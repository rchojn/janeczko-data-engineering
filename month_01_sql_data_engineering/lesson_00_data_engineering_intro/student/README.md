## Co masz zrozumiec

Po tej lekcji masz umiec opowiedziec prostymi slowami:

- skad biora sie dane w firmie,
- dlaczego baza aplikacji nie wystarcza do raportowania,
- czym rozni sie OLTP od OLAP,
- czym jest data lake / warehouse / mart,
- po co sa Bronze, Silver i Gold,
- gdzie wchodza SQL, DuckDB, Parquet, dbt i Airflow,
- dlaczego najpierw uczymy sie fundamentow na malych danych.

## Najwazniejsze zdanie

Data Engineer nie tylko przenosi dane. Data Engineer buduje zaufany przeplyw danych, z ktorego ktos podejmuje decyzje.
